# Dataset cards and integrity rules

This repository does not distribute clinical images. Get the public releases directly from the authors; cite them in any resulting work. The downloader pins SHA-256 for the four files validated during implementation. If upstream bytes change, do not silently accept them. Investigate the new release and version the protocol.

| Cohort | Source, access and annotation contract |
|---|---|
| BUS-BRA (development) | [Zenodo v1](https://zenodo.org/records/8231412); Gómez-Flores, Gregorio-Calas & Pereira, [Medical Physics](https://doi.org/10.1002/mp.16812). Read LICENSE.txt and retain its notice if redistributing. bus_data.csv supplies ID, Case (patient), and Pathology. CC BY 4.0. December 2023 workbook uses CaseID, one case per patient. Union the tumor filenames separated by ampersands, never the “other” masks. ## Eligibility, IDs and duplicates

- Do not use data from employers or nonpublic clinical sources. Prepare all three cohorts together for the MSc study; a BUS-BRA-only manifest is useful for an isolated pilot but cannot be frozen as the full study.
- Exclude BUS-UCLM Doppler, marked and combined frames before scoring, recording **all** applicable flags. Exclude a lesion-positive row with no mask. Quarantine a UCLM image/mask size mismatch with both dimensions logged; do not stretch the annotation or assume an empty target. This rule was set from raw-data integrity checks, not predictions. Unknown labels/colors, unexpected IDs and contradictory positive/normal status fail closed.
- Hash files and decoded grayscale pixels. Group identical source scans and patient IDs before splitting. Screen different patients/cohorts for perceptual difference hashes within Hamming distance 3; this is a duplicate **screen**, not proof of leakage or proof that no duplicates exist. Inspect unresolved pairs for shared underlying frames, not diagnosis or model performance. Do not automatically mark all candidates distinct.
- For flagged pairs, make a local JSON object whose keys are the exact strings in duplicate-review.json → pending; values must be “duplicate” or “distinct” (plain JSON strings). Rerun the same prepare command with --decisions review.json. Confirmed duplicate source patients must stay in one fold. Quarantine external copies that overlap the source, both external sides of cross-external overlaps, and ambiguous within-external copies attributed to different patients. Keep the adjudication file with the private study record.
- If published source folds violate group invariants, rebuild five pathology-stratified grouped folds with seed 2411 before any training. Stop if patient grouping cannot be verified. Never use a random frame-level split.
- The local manifest contains absolute paths, reference labels and hashes; use it for reproducibility on that machine. Only image arrays and a first-pass mask/probability map feed inference. Ground truth is loaded after the two candidate masks have been produced. Share vetted aggregate counts and hashes, not patient-level manifests by default.

## Interpreting cohort sizes

The releases contain 1,875 BUS-BRA images from 1,064 patients, 256 BrEaST cases, and 683 BUS-UCLM frames from 38 patients **before** exclusions. The UCLM flags leave 521 rows before geometry checks. Eleven of those released pairs have unequal image and mask dimensions. Report the actual eligible counts from counts.json, plus the exclusion lists and any duplicate adjudication; do not quote release sizes as evaluation denominators. Cohorts do not necessarily annotate the same number of lesions per scan.

**Observed preparation run (18 November 2026, no model predictions):** published BUS-BRA folds passed patient checks, with 376/385/366/365/383 images respectively. BrEaST retained 256 cases (4 normal). For BUS-UCLM, 162 frames were excluded by acquisition flags, 11 by geometry, and 6 by the exact-duplicate quarantine. The resulting UCLM cohort had **504 scans, 36 patients and 391 normal scans**. The three-cohort screen had no unresolved near-duplicate pairs. These counts are a data check, not a segmentation result.
